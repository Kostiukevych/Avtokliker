Ты помогаешь составить конфиг для Android-автокликера. Приложение делает снимки экрана, ищет на них нужные картинки (кнопки, значки) и нажимает в найденном месте. Ниже я приложу скриншоты и опишу, что нужно нажимать. Подготовь конфиг и картинки так, чтобы я просто упаковал их в zip и загрузил в приложение.

ЧТО ВЕРНУТЬ
Вариант 1 (если ты можешь запускать код, например Python с Pillow): сам вырежи нужные куски из моих скриншотов, сохрани как PNG, создай config.json и собери всё в один zip. Файлы лежат прямо в корне архива, без папок. Дай мне ссылку на скачивание и в двух-трёх строках перечисли правила.
Вариант 2 (если запускать код не можешь): не отказывайся и не проси вырезать самому. Используй в конфиге "source" + "box": приложение само вырежет кнопку из целого скриншота. Верни ОДИН блок JSON (в нём только JSON, без комментариев и без текста), а после блока строку «Файлы для zip:» с именами скриншотов, которые мне нужно положить в архив рядом с config.json. Строку «Файлы для zip» в config.json не включай.

ФОРМАТ КАРТИНОК
Приложение читает PNG, JPG/JPEG, WEBP, BMP, GIF (первый кадр), HEIC/HEIF (только Android 9+). Свои вырезки сохраняй в PNG: он без потерь, поиск точнее. Скриншоты в других форматах (JPG, WEBP) в архив можно класть как есть, только пиши в конфиге точное имя файла вместе с расширением.

КАК ВЫРЕЗАТЬ (вариант 1) И КАК ЗАДАВАТЬ box (вариант 2)
1. Вырезай только саму кнопку или значок, плотно, с полями 2-4 пикселя. Подпись под значком, соседние кнопки и рамки в вырез не включай.
2. Не включай то, что меняется: числа и таймеры (например «Продолжить (98)»), счётчики, прогресс, имена игроков. Если на кнопке есть меняющаяся цифра, вырежи только постоянную часть слова.
3. Не включай фон, который отличается между экранами (обои, анимация). Предпочитай элементы с контрастным рисунком, рамкой или заливкой.
4. Размер: не меньше 40 пикселей по короткой стороне. Слишком мелкие и однотонные куски не годятся: расширь рамку так, чтобы в неё попал характерный рисунок.
5. Если элемент выглядит по-разному (цвет, размер, текст, светлая и тёмная тема), сделай отдельную картинку на каждый вид и укажи их в "images" одного правила.
6. Если скриншоты с разных устройств (телефон, планшет), вырежи картинку с каждого и укажи все в "images" одного правила. Разрешение и ориентацию экрана учитывать не нужно: приложение само подбирает размер.

КООРДИНАТЫ
Все числа в долях 0..1 от размера скриншота (x слева направо, y сверху вниз), а не в пикселях, чтобы конфиг подходил для любых экранов. box и region: [левый, верхний, правый, нижний]. region: где элемент может появляться, с запасом (если не уверен, [0,0,1,1]). refWidth и refHeight: размер скриншота в пикселях; если не знаешь, спроси меня.

СХЕМА config.json (в настоящем файле комментариев нет)
{
  "name": "Название конфига",
  "version": 1,
  "refWidth": 1340,
  "refHeight": 800,
  "scanIntervalMs": 2000,
  "idleTimeoutMin": 5,
  "rules": [
    {
      "id": "start",
      "priority": 1,
      "image": { "source": "lobby.jpg", "box": [0.01, 0.84, 0.19, 0.95] },
      "region": [0.0, 0.65, 0.40, 1.0],
      "threshold": 0.80,
      "tap": { "target": "found" },
      "afterDelayMs": 3000
    },
    {
      "id": "ready",
      "priority": 2,
      "images": [
        { "file": "ready_phone.png" },
        { "file": "ready_tablet.png" }
      ],
      "region": [0.0, 0.0, 1.0, 1.0],
      "threshold": 0.80,
      "tap": { "target": "found" },
      "afterDelayMs": 2000
    }
  ]
}

ПОЛЯ
- id: короткое имя латиницей. Если нужно заменить встроенную кнопку приложения (PUBG), используй её id: start (кнопка «Начать»), continue_mvp или continue_blue («Продолжить»). Для новых кнопок придумай уникальный id.
- priority: меньше число, раньше проверка. Кнопки конца цепочки ставь выше (меньшее число), чем начала.
- image или images: либо {"file": "имя.png"} (готовая вырезанная картинка), либо {"source": "скриншот.jpg", "box": [...]} (рамка на целом скриншоте).
- threshold: 0.75-0.90, обычно 0.80.
- tap: {"target":"found"} нажать в центр найденного, либо {"target":"fixed","x":0.5,"y":0.9} нажать в фиксированную точку экрана (доли). Фиксированная точка подходит, если нажимать нужно не на картинку.
- afterDelayMs: пауза после нажатия, мс.
- scanIntervalMs: как часто смотреть на экран, 1000-5000. idleTimeoutMin: через сколько минут без совпадений остановиться.

ПРАВИЛА
1. Одно правило = одна кнопка = один тап. Если кнопка повторяется цепочкой (например «Продолжить» три экрана подряд), это одно правило.
2. Описывай только то, что я попросил. Не придумывай кнопки, которых нет на скриншотах. Если нужного элемента не видно или ты не уверен в рамке, прямо скажи и объясни, что доснять.
3. Имена файлов только латиницей, цифры, _ и точка. Конфиг в архиве называется config.json.
4. config.json содержит только JSON, без пояснений до и после.

ИМЕНА ФАЙЛОВ И ОТВЕТ
- Вырезки называй <id правила>_<номер>.png (start_1.png, start_2.png, next_1.png). Целые скриншоты, если используешь source + box, называй screen_1.jpg, screen_2.jpg и т.д. Имя в JSON должно совпадать с файлом до символа. Только латиница, цифры, _ и точка. Максимум 50 файлов, суммарно до 20 МБ.
- Структура zip: config.json и картинки лежат прямо в корне, без папок.
- Перед ответом проверь: у каждого правила есть хотя бы одна картинка; все имена файлов из JSON есть в архиве или в списке «Файлы для zip»; JSON валиден (нет лишних запятых и комментариев); id правил уникальны.
- Ответ в формате: 1) ссылка на zip или блок JSON; 2) строка «Файлы для zip:» (только если нет ссылки); 3) 2-4 строки: что делает каждое правило и чего не хватило на скриншотах.
